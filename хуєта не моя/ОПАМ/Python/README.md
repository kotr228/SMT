# ОПАМ — програми на Python (Нагібін М. В., варіант 15)

Відкрити у VS Code: **File → Open Workspace from File… → `ОПАМ.code-workspace`**
(або відкрити окрему папку `ЛР1` … `ЛР4` через **File → Open Folder**).

Потрібно: Python 3 і розширення **Python** (ms-python.python) для VS Code.

Запуск: відкрити `main.py` і натиснути **F5** (або ▶ «Run Python File»),
або в терміналі VS Code: `python main.py`.

| Папка | Завдання |
|-------|----------|
| ЛР1 | Кусково-задана функція y (a = 2.5), оператор if |
| ЛР2 | Таблиця y = ctg(x⁴ − 0.55), x ∈ [−1; 1], h = 0.1, цикл while |
| ЛР3 | arth x через ряд x + x³/3 + x⁵/5 + …, цикл for |
| ЛР4 | Масив D(30): кількість і добуток додатних елементів |
